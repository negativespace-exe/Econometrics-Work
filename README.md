# Econometrics-Work
Collection of Assignments completed for Econometrics class, which use synthetic. randomly generated, and observed data to explore econometric analysis. 

1. Supply and Demand Curves
2. Linear Regression
3. OLS (Ordinary Least Squares)
4. Heterscedasticity and Autocorrelation
5. GLS/WLS (Generalized/Weighted Least Squares)
6. Endogeneity and IV/2SLS Models
